AgentOS P1 · 真实链路

一句话任务 → LLM 规划 → 只读真实库 → 自动报告 → 人工审批 → 多通道投递（失败自动回退）

可中断

高风险步骤 interrupt() 停下等人 approve / reject。

可恢复

SQLite checkpoint 持久化，进程退出后新进程 resume，不重跑已完成步骤。

只读安全

mode=ro + query_only，固定 SQL 参数化，工具层无写库能力。

零丢件

投递 auto：Telegram → 本地 IM → 本地收件箱，失败自动回退并留审计。

快速开始

  1. powershell -File setup.ps1 建环境（uv + 固定版本 + 冒烟测试）
  2. python poc.py demo 跑 5 个场景（中断 / 恢复 / 只读 / 拒绝 / 状态）
  3. python poc.py run --task "查一下本周未完成的 tasks，按负责人汇总后发给我"
