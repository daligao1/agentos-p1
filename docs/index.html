它解决什么

  • 可中断：高风险动作 interrupt() 等人工 approve/reject
  • 可恢复：SQLite checkpoint，进程重启后继续
  • 只读安全：mode=ro + query_only，固定 SQL 参数化，无写库工具
  • 零丢件：投递失败自动回退本地收件箱并审计
